Task 3 of 16 — Concatenation — Complexity: L-2

The "+" symbol represents concatenation. Select the correct output. 

a = "123 Main St, "
b = "Springfield, "
c = "OH"

a + (b + c)
  1. 1. "123 Main St, (Springfield, OH)" ✓
  2. 2. "123 Main St,Springfield,OH"
  3. 3. "123 Main St,(Springfield,OH)"
  4. 4. "123 Main St, Springfield, OH"

Correct answer: option 1 → 123 Main St, (Springfield, OH)

Design note: Under the pseudo-syntax, parentheses in the expression are preserved in the output as grouping markers. Option 4 is the naive evaluation result that ignores the grouping display rule.

Task 7 of 16 — Concatenation — Complexity: L-4

The "+" symbol represents concatenation. Select the correct output. 

"World, " + 1 + 2 + 3 + (1 + 1 + 1 + 1) + ("5" + (6 + 7))
  1. 1. "World, 123(\"5\"(67))"
  2. 2. "World, 123(\"5\"))"
  3. 3. "123(1111)(\"5\"(67)), World"
  4. 4. "World, 123(1111)(\"5\"(67))" ✓

Correct answer: option 4 → World, 123(1111)("5"(67))

Design note: Under the pseudo-syntax, numeric values are not arithmetically evaluated; they are treated as literal tokens. Parenthesized subexpressions are displayed with their grouping parentheses preserved in the output. Therefore (1+1+1+1) renders as (1111) and (6+7) renders as (67). This differs from standard Python/Java semantics where (1+1+1+1)=4 and (6+7)=13.

Task 8 of 16 — Interpolation — Complexity: L-4

The "{ }" symbol represents interpolation. Select the correct output. 

"{1} {2} {3} {({9} {9} {9} {1})} World { ({\"5\"} {(67)} )}"
  1. 1. "1 2 3 (9 9 9 1) World (\"5\" (67) )" ✓
  2. 2. "123(9991)World(\"5\"(67))"
  3. 3. "1 2 3 ({9} {9} {9} 1) World (\"5\" (67) )"
  4. 4. "1 2 3 9 9 9 1 World \"5\"67"

Correct answer: option 1 → 1 2 3 (9 9 9 1) World ("5" (67) )

Design note: The pseudo-syntax used in this experiment is language-neutral and does not correspond to any specific language runtime. Nested interpolation markers {(...)} are valid in this pseudo-syntax: the outer {} triggers interpolation and the inner () marks a group whose contents are also interpolated. This would not compile in Python or similar languages, but is intentional here to test comprehension of nested structure without language-specific bias.

Task 10 of 16 — Interpolation — Complexity: L-3

The "{ }" symbol represents interpolation. Select the correct output. 

a = 5
b = 6
c = 4
d = 10

"a = {a} b = {d} c = {b} d = {c}"
  1. 1. "a = 4 b = 5 c = 6 d = 10"
  2. 2. "a = 5 b = 10 c = 6 d = 4" ✓
  3. 3. "a = {a} b = {d} c = {b} d = {c}"
  4. 4. "a = a b = b c = b d = c"

Correct answer: option 2 → a = 5 b = 10 c = 6 d = 4

Design note: This task deliberately aliases label names to different variables (e.g., label 'b' uses variable {d}) to test careful tracking of placeholder-to-variable mappings.

Task 11 of 16 — Concatenation — Complexity: L-4

The "+" symbol represents concatenation. Select the correct output. 

"(0 " + " 1)" + "(1 " + " 1)" + "..." + m + n-1 + l-2 + " = m(m+1)/2 = O(m^2)"
  1. 1. "(01)(11) ... mn-1l-2 = m(m1)/2 = O(m^2)"
  2. 2. "12...mn-1l-2=mm1/2=0m^2"
  3. 3. "(0 1) (1 1) ... m n-1 l-2 = m(m 1)/2 = O(m^2)" ✓
  4. 4. "1 2 ... mn-1l-2 = mm1/2 = 0m^2"

Correct answer: option 3 → (0 1) (1 1) ... m n-1 l-2 = m(m 1)/2 = O(m^2)

Design note: This task tests comprehension of concatenation across a complex mathematical expression. The '+' inside the literal strings does not represent concatenation — only the outer '+' operators between quoted segments do. The expression also includes symbolic variables (m, n, l) that are not defined, requiring participants to treat them as literal tokens.

Task 12 of 16 — Interpolation — Complexity: L-4

The "{ }" symbol represents interpolation. Select the correct output. 

"{(0 2 1)} {(1 2 1)} {...} n {m-1} {l-2} = m(m 1)/2 = O(m^2)"
  1. 1. "(0 2 1) (1 2 1) ... n m-1 l-2 = m(m 1)/2 = O(m^2)" ✓
  2. 2. "3 4 ... n m-1 l-2 = m(m 1)/2 = O(m^2)"
  3. 3. "(021)(121) ... nm-1l-2 = m(m 1)/2 = O(m^2)"
  4. 4. "... n m-1 l-2 = m(m 1)/2 = O(m^2)"

Correct answer: option 1 → (0 2 1) (1 2 1) ... n m-1 l-2 = m(m 1)/2 = O(m^2)

Task 16 of 16 — Interpolation — Complexity: L-3

The "{ }" symbol represents interpolation. Select the correct output. 

domain = "example.com"
query = "?user=john"
protocol = "https://"
path = "/home"

"https://protocol/{domain}/path/{query}"
  1. 1. "https://protocol/home/?user=john"
  2. 2. "https://example.com//home/?user=john"
  3. 3. "https://protocol/example.com/path/?user=john" ✓
  4. 4. "https://https:///example.com//home/?user=john"

Correct answer: option 3 → https://protocol/example.com/path/?user=john

Design note: Only {domain} and {query} are interpolation placeholders. The words 'protocol' and 'path' in the template string are plain text, not placeholders. This tests whether participants distinguish between literal text and interpolation markers.
